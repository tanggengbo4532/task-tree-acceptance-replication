# 证据索引 · <项目 / 轮次 / 日期>

> 用途：给验收报告/归档/论文一个可追溯的**证据入口**；只列真实存在的文件与路径。生成方式：`python tools/evidence/manifest.py --dir <证据目录> --out evidence-index.md`（可手工补充说明）。

## 1. 证据目录与报告

| 类型 | 路径 | 说明 |
|---|---|---|
| 测试报告 | `<…/tester-report.md>` | 逐节点结论+证据编号+未达成项 |
| 经验库 | `<…/EXPERIENCE.md>` | S/F/R 与验证状态 |
| 开发探针 | `<…_dev/roundNN/>` | 审计/修复报告/探针日志 |
| 归档 | `<giveUser/…>` | 六项归档/验收报告（版本化） |
| 指标 | `<metrics 输出>` | 用时/token **估算**（标注口径） |

## 2. 截图分组（前缀 → 张数 → 用途）

| 前缀 | 张数 | 对应节点/轮次 | 关键帧 |
|---|---|---|---|
| `rNN_` | <N> | <复现轮> | `<rNN_01_before.png>`（阻塞）、`<rNN_09_after.png>`（通过） |
| `rNNb_` | | <复测轮> | |
| `rNN_hold_*` | | 卡顿采样 | `<rNN_hold_..._r0.png>` |
| `rNN_walk_*` | | 轻按吞键采样 | |

## 3. 日志/证据文件

| 文件 | 期望 | 说明 |
|---|---|---|
| `rNN.err.log` | **0B** | stderr；非 0B 需解释（警告/崩溃/取证） |
| `rNN.out.log` | 正常 | 启动参数/引擎信息 |
| `quit_trace.log` | 按需 | 退出取证（时间/场景/坐标/隐藏状态） |
| 探针 JSON | — | walk/hold/fps 输出（含数字与采样参数） |
| `manifest.json` | — | 证据清单（路径/sha256/mtime/分组） |

## 4. 引用建议

- 报告/归档引用**原路径**（相对报告文件用相对路径；截图必须可 Test-Path）；
- 只引用已核实的证据编号；不引用被作废轮次证据（作废需标注）；
- 论文/对外引用时注明"构建 hash + 轮次 + 证据前缀"，避免只给结论。

## 5. 缺口

- <未覆盖/未取证项，如：某场景未走到、某日志缺失>；
- <证据丢失/作废说明>。
