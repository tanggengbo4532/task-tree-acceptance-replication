# B 条件1 使用的经验规则（与副本）

> 这是从团队真实经验库抽取给**自动化执行器**的规则集合；不代表 LLM 内部知识，也不是人类受试者实验。

## 规则（executor）

1. **HUD 严格跟随**：每步读取游戏当前 `_a14g_key`，按该方向键；不自行改名/猜测屏幕对角语义。
2. **撞墙恢复**：目标格不可走（`_tap` 返回 block）时，读取 HUD 当前替代方向并尝试；仍不可走则记录 invalid，不原地循环。
3. **等待/剧情恢复**：若 VM/dialog 活跃，按 Space 有界推进（≤120帧），不把“剧情对白”误判为死锁；真实战斗不做 auto-win。
4. **锚点方法**：先载入指定真实 `.sav`（团队槽2），关闭遗留对话框/重置战斗标记，再开始读取 HUD/N；不从内存伪造状态。
5. **计数口径**：steps 含 alternate tap；invalid 为无位移 tap；wrong_direction 为移动后到 target 的 metric 增加；repeated_failures 为同一受阻点≥3次。
