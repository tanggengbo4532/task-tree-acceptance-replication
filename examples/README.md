# Integration examples

- `quickstart.py` runs the local notes app example in Edge or Chrome.
- `web-app.json` and `generic-desktop.json` show backend configuration.
- `task-tree.json` and `steps/notes-A1.json` show an acceptance tree and a node's inputs.
- `pal98-godot.json` and `pal98-walk-specs.json` are PAL98-specific examples. Some labels in the test data match the original game UI.

Copy the appropriate configuration into your project and set the launch command, target locator, evidence directory, and test data. Use one target instance. See the [backend contract](../scripts/backends/CONTRACT.md).
