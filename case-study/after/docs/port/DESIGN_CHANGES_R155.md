# R155 scene55/map59 装饰增强版（黑边遮挡带 + 村道踩踏痕 + 更密簇）

## 用户反馈
- R154 方向对但还不够“不突兀”：左侧黑色锯齿边界明显、主路径无视觉引导、草地仍空。
- 要求：只视觉层，不改 blocked/路径/N；用同 tileset；不挡路、不现代元素。

## 本版改动（world.gd `_decorate_map59`，只写 bottom/layer_top 图像）
1) **左侧黑边遮挡带**
   - 原版相机边界 x=160 左侧为不可走图外区；此前只覆盖到 x+origin，最左 16px 黑锯齿仍在。
   - 改为直接按**图像坐标** x=0..192 密铺深色草变体（帧 10/20/63/21/41/81/82），top 层随机撒草丛/灌木感 overlay；
   - 每行位置/高度随机扰动，避免整格对齐；连续覆盖黑边。
2) **村道踩踏痕（视觉引导）**
   - 沿真实引导路径 (160,432)→(160,912)→(176,984)→(256,1024)→…→evt926(192,1296) 铺土色/干草变体
     （帧 16/413/507/85/15），路缘随机撒碎石（帧 95/85/61/37/30）和干草变体；
   - 只是图像，不写 _bottom_index/blocked；玩家仍走原可走格。
3) **更密草地簇**
   - 扩到 24 个簇、14 个装饰点/簇；地被色块 + 随机 top 花/草/碎石；
   - 草地中央、村道两侧、evt926 方向均有分布；
4) **两处石堆地标**（208,560 / 256,1160）：同 tileset 碎石 top overlay，纯视觉。
- **不修改**：`_bottom_index/_top_index/blocked/has_content`、事件表、碰撞、BFS/路线。
