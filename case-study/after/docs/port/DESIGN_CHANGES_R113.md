# R113 第3章 scene54 韩医仙家「灵儿剧情循环/A26 交药引不触发」修复

## 用户现场（构建 3c8863f，槽1 只读，scene53 (896,896)，a25=1、a26_clue=1、item76=2）
- HUD 指 evt886 → SPACE 进 scene54 (1440,576)【脚本】→ 自动播 4 页剧情 → **自动回 scene53 (896,896)**；
  再进 scene54 又播同一段；A26 交药引永不触发，存档无 a26_stage。

## 根因
1) `A25_TALK_SCRIPT=10081`（韩医仙求医剧情）尾部会由脚本自身切回 scene53（0x0059）。
   `_update_a25` 的完成判定要求“脚本结束后仍停留在 scene54 且 idle”，场景已被切走时来不及执行 →
   **a25_stage 一直为 0** → 每次进 scene54 都重播求医剧情（死循环）。
2) A26 交药引（原 R104 逻辑）要求 `scene54 && !player_busy && !dialog && vm 空闲` 累计 1.2s；
   同样因剧情脚本立即切走/持续 busy，**a26_stage 永远不推进**。
3) 剧情脚本会把队伍放到 **(1440,576)** 一带（实际 clamp 到 (1392,576)），该格是**孤立可达格（四周不可走）**；
   剧情后队伍停在这里，HUD 无方向/0 格，看起来“卡死”。

## 修复（world.gd）
1) `load_scene`：离开 **scene54** 时按“剧情已实际播放”补写真实进度：
   - `_a25_talk_started` → **a25_stage=1**（求医剧情已播完，不论是否已切回 scene53）；
   - 背包有糯米（`_c3_has_rice()`）→ **a26_stage=1**（交药引完成）。
2) `_update_a26` 交药引：条件改为只要 `scene54 && a26_clue && a26_stage<1`，累计 1.2s 即推进，
   **不再等待对白/idle 结束**（避免剧情脚本切场景导致永不触发）。
3) `_update_a25` 完成 与 `_update_a26` 交药引完成后：若仍在 scene54，把队伍从剧情孤立格
   **放回韩医仙家门口安全格 (1280,880)**，保证 HUD 能指向出口 evt904。
4) HUD：scene54 拿米未交时显示「交药引（自动对白，按空格翻页）」；a26_stage=1 后
   「回白河村（出村前往将军冢）」→ evt904。
