# R105 修复说明（装备页空白 / 白河村商铺进入 / HUD 方向复核）

## 1) 装备界面空白（全红格）修复
- 现象：菜单→物品→装备→选中装备后，画面只有 FBP#1 红色背景，角色/装备/属性/描述全部不显示。
- 原因：旧 `menu_equip.gd` 完全依赖 FBP#1 背景 + 调色板索引色绘制，实机该页文字不可见（背景图可见、所有 Label 不可见）。
- 修复：`EquipItemController.build()` 改为**自绘高对比面板**（不再调用 bg_fbp）：
  - 角色列表（可选角色亮色/不可装备灰色）；
  - 六部位当前装备名（头戴/披挂/身穿/手持/脚穿/配带）；
  - 五项属性（武/灵/防/身/吉）；
  - 待装备物品名+数量；
  - **装备效果行**（与商店/背包同源：`头戴｜防御+4｜可装备：李逍遥`）；
  - 操作提示。
- 颜色全部用显式 Color（不依赖调色板），任何场景下可见。
- headless 验证：进入装备页后 Label 列表包含 `装备 / 李逍遥 / 林月如 / 当前装备 / 头戴：头巾 / … / 待装备：木剑 x1 / 手持｜武术+2 身法+3｜可装备：李逍遥/林月如 / 提示行`。

- 白河村（scene50，地图46）内**没有**可直接交互的商店 NPC；商店在 **scene51（地图58，商铺街）**。
