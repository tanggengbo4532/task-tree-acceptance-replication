# R108 修复：白河村 evt834「按空格交谈」卡死

## 现象
- tester 在 scene50 (816,856) 出现「按空格交谈」（日志 `ia=834 kind=npc`）→ WASD/方向全部无效，
  SPACE 8+ 次无对白；HUD「去韩医仙家求医 ←90格」的唯一路径经过该格，第3章被卡死。

## 根因
- R105 的第3章通用 NPC 扫描把**所有 mode<4 且有触发脚本的事件**都当作可交谈 NPC 给出 SPACE 提示；
- evt834 运行期位置 (880,840)，mode2，trigger 脚本 9917（4 条对白词 3498-3501），是装饰村民/自动 NPC，
  与剧情交互无关；玩家按 SPACE 后脚本/对白状态异常，移动被锁且无可见对白；
- 从 (896,848) 到韩医仙家入口 evt803 的 HUD 路径恰经过 (816,856)，导致唯一路线被卡死。

## 修复
- `world.gd _scan_extra_interact` 第3章分支：只有**触发脚本含 0x0026/0x0027（真商店）**的事件才给
  「按空格进入商店」提示；其它 mode<4 事件不再显示“按空格交谈”，不锁定移动，可直接穿过/绕行。
- A24/A26 剧情线索仍由专用交互分支处理；mode>=4 的 SPACE 门优先逻辑不变。

## 验证（headless，槽1 只读，a24=1）
- (816,856)：interact=0，kind/prompt 空；按 ↑ 可移动 (816,856)→(816,848)。
- (896,848) HUD 目标 evt803 (1632,704)，剩90格；HUD 路径前段（真实地砖）：
  `L2 D1 L3 U3 L1 U3 L1 U8 R9 D1 R1 D1 R15 D1 R1 D1 R1 D1 R1 D1 R4`（共90步，经过 (816,856) 现在可直接走）。
- boot exit0；槽1/2 未写。
