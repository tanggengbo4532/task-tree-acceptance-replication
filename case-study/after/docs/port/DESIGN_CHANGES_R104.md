# R104 修复与装备效果显示（白河村节点 / 商店/背包装备）

## B) 白河村「打听韩医仙线索」无交互、节点不推进（用户 bug）
### 真实数据（只读用户槽1 08:45 档，scene50 (896,848)）
- 场景：scene50 白河村（地图58），入口 evt790 script 9776（0x0059 场景50 + 落点）。
- 目标事件：**evt835（A24_CLUE_EVT）**；Sss 默认 (928,864)，用户存档运行期位置 (880,856)；
  trigger mode=2（**不是 touch 模式**，原版语义为走近后按 SPACE 搜索交互）。
- 脚本：A24 线索对白 **9922**（消息词 3502-3504）；evt835 默认 trigger 9926（词 3505-3508），
  存档里 trigger 已被改为 9922（A24 系统写入）。相关事件 evt833 (A26_CLUE_EVT，糯米线索 9909)。
### 根因（三处叠加）
1. `_update_a24` 旧门槛 `a23_stage>=1`；本移植没有任何地方给 a23_stage 赋值 → A24 自动线索永远不启动；
2. world 的 touch 触发只处理 `mode>=4`（mode<4 由 SPACE 搜索），而 `_scan_extra_interact` 没有 scene50 分支
   → evt835 没有 SPACE 提示/交互；
3. 结果：HUD 指向 evt835 并显示“已到触发点”，但按空格/靠近都无事发生，a24_stage 不变，HUD 卡住。
### 修复（world.gd）
1. `_scan_extra_interact` scene50 增加 **a24clue** 交互：距 evt835 半径 112 内提示
   「按空格打听韩医仙线索（第 3 章）」；SPACE 执行真实脚本 A24_CLUE_SCRIPT(9922)、设 `_a24_clue_started`。
2. `_update_a24`：去掉 a23_stage 门槛（改为 a18_stage>=1 的章节进度），删除自动弹对白，改为对白结束写
   **a24_stage=1**，HUD 自动切下一节点「白河村：去韩医仙家求医（第 3 章）」→ evt803。
3. 第3章链同源补齐：
   - A25 求医对白完成写 **a25_stage=1**，HUD 切「白河村：打听糯米线索」→ evt833；
   - `_scan_extra_interact` scene50 增加 **a26clue** 交互（evt833，半径112，脚本 9909），对白后发糯米 item76、
     `a26_clue=1`，HUD 切「回韩医仙家交药引」→ evt803。
### 验收（headless，槽1 只读）
- 载入 scene50：`_interact_kind=a24clue`、提示「按空格打听韩医仙线索（第 3 章）」；HUD「目标 白河村：打听韩医仙线索」。
- 按 SPACE：执行真实脚本 → a24_stage 由空变 **1**；HUD 变
  「目标 白河村：去韩医仙家求医（第 3 章）｜下一步按【←】键 · 剩 90 格」，target evt803 (1632,704)。

## A) 装备效果显示（商店买/卖 + 背包/装备菜单）
### 数据源（真实，不编造）
- 装备效果在 **Data#5 OBJECT 物品的 `script_on_equip` 脚本**里：`0x0018` 指定部位，
  `0x0017/0x001A/0x0019` 写入 PLAYERROLES 字段增量（17 武术/18 灵力/19 防御/20 身法/21 吉运/22 毒抗/23-27 抗风雷水火土/7 最大HP/8 最大MP）。
- 可装备角色 = OBJECT `flags` 的 `0x40<<role` 位（与装备界面判断同一规则）。
- 部位：0 头戴、1 披挂、2 身穿、3 手持、4 脚穿、5 配带。
### 改动
- `pal_tables.gd` 新增 `item_equip_effect_text()`：三段式 `部位｜属性增量｜可装备角色`。
- `menu.gd item_desc_lines()`：背包/装备选择列表的描述追加装备效果（与 script_desc 原文同列）。
- `menu_equip.gd`：装备确认界面物品名下方显示同一效果行。
- `shop.gd`：购买/出售页选中物品效果优先显示消耗品效果；装备类回退到装备效果（同源）。
### 样例（真实解析结果）
