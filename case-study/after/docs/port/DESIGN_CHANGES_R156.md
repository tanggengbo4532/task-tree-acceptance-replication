# R156 遇敌过频根因 + Ctrl 复用扩展

## A) 遇敌过于频繁（scene71 map63 等）
- 用户最新槽1：scene71，abs (1248,464)，map63；该图 evt1382-1386 为**可见遭遇事件**，
  auto 脚本 41099/41084 用 0x4C 持续追击；触发脚本为 `0x7 team,41075,41073`。
- 根因：0x0007 = `(team, op1=失败/GameOver, op2=胜利清场)`：
  - **41075**：失败分支（“胜败乃兵家常事…”+0x4E 读档）；
  - **41073**：胜利分支（`0x4B` 设置怪物 vanish 清场）。
  - R153 让胜利不跳 a2、顺序执行 → 随机遭遇战胜利后**怪物没有 vanish**，立刻再次追击 → 用户体感“几步一遇敌”。
- 修复（script_vm.gd R156-BATTLEBRANCH-3）：
  - `BATTLE_WON/BATTLE_FLEED → jump(a2)`（a2 非0；0 则顺序执行，如 A33 剧情战）；
  - `BATTLE_LOST → jump(a1)`（a1 非0；0 则顺序）。
- headless 验证（槽1只读）：
  - scene71 evt1385 (1232,456)：触发战斗 team33，模拟胜利后 evt1385 **vanish=-15（vanish 已设置）**，VM 正常结束；
  - 位置/HUD 不变；随机怪清场，不再原地重复追击。

## B) Ctrl 复用上回合操作（battle.gd R156-CTRLREUSE-1）
1) **缓存范围**：上一回合所有非“跳过”指令（普通攻击/防御/技能/合击）都记录，不再只记录技能/合击。
2) **普通攻击复用**：Ctrl → 重新选敌目标 → 复用普通攻击。
3) **技能 MP 不足降级**：上回合是技能但当前 MP 不足 → 自动改为普通攻击（提示“MP不足，复用改为普通攻击”，不报错/不空过）。
4) **跨战斗保留**：每条指令按角色 id 写入 `PALState.vars["battle_reuse_actions"]`；
   战斗结束不清空；下一场战斗/读档后第一回合 Ctrl 从 vars 懒加载复用。
5) 防御也可复用；选敌/选队友目标都重新走正常目标选择，避免沿用旧索引。
- headless 验证：
  - 战斗实例 A `_reuse_store(0, 普攻)` → vars 出现 `{"type":2...}`；
  - 新建战斗实例 B `_reuse_fetch(0)` 取回普攻 type=2 → **跨战斗可复用**；
  - 技能 type=3 同样跨实例保留；MP 不足降级为普攻分支已实现（需读档实战复核 UI 流程）。
