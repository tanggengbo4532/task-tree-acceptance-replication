# R241 scene85 蓝笔 tile 最终可走集实现（用户确认版）

## 用户最终规则
- 黄框冲突格全部算可走（蓝笔覆盖、元素为墙/水/屋顶/草的 tile 也放行）；
- 目标门 tile (1152,432) 蓝笔覆盖52.7% → 可走；
- 起点 (784,440) 是墙顶 → 读档救援到最近可走 tile；
- 未被蓝笔覆盖/同类多数判不可走仍不可走。

## 数据与规则
- map80：**64×128×2** tile（h=0/1），每 tile 32×16 菱形；
- 蓝笔从用户 1400 图最近邻上采样到 2064×2056，按 slot 面积算覆盖率，阈值 **25%**；
- 同类局部多数：bottom id，Chebyshev 半径4，>50% → 可走；同 id 样本<4 回退全图比例；
- **最终可走集**：同类多数可走（绿）∪ 蓝笔覆盖(≥25%) tile（含黄框冲突，用户确认全部放行）；目标门 (1152,432) 已被覆盖，包含在内；
- 结果：可走 2357 tile；蓝笔覆盖非地面冲突1306个（水/void 909、墙329、屋顶24、草44），全部按用户确认放行。

## 代码实现（R241-S85TILE-1）
1. 生成 16384 slot 的 **2048 字节位图**，base64 常量 `S85_WALK_BITS_B64` 写入 `world.gd`；
2. `_s85_ground_cell_ok(p)`：按像素算 slot，查位图；
3. `_is_obstacle` / `_walk_target_ok` 在 scene85 **最前**同源检查（移动/HUD 一致）；
4. `_s85_wall_rescue()`：读档/落点不在白名单 → 扫描最近可走 tile 中心，设置队伍落点；
5. load_scene 末尾调用救援；不开放未蓝笔覆盖的墙/水/void（位图决定）。
