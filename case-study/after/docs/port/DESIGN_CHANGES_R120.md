# R120/R121 水面不可走 + 将军方向 N 不准 修复

## A) 水面不可走（真实图块数据）
- 只读用户槽1 最新档（18:00，sha `E0F9F00…`）：scene50，绝对位置 **(224,1448)**（map46）。
- 该格是 **map46 tile 307**：真实 MAP.MKF 图块号 307 = 水面底图（整块纯色菱形水面），
  原版 MAP 数据里**没有 blocked 位**（`d & 0x2000 == 0`），所以旧端口按“无碰撞位=可走”把人放上了水面。
  桥/木栈道是同一格的 **top 层 overlay**（top>=0），例如 (640,1608) 等格。
- 修复（pal_map.gd，R120-WATER-1）：
  - 新增按地图/图块号的数据表 `WATER_TILE_IDS = {46: [307]}`；
  - `is_open_water(x,y,h)`：**水面底图且该格无 top overlay** 才算开放水域（有桥/栈道 overlay 的格保持可走）；
  - `is_blocked()` 对开放水域返回 true → `_is_obstacle`/`_walk_target_ok`/HUD 距离场同源生效。
  - 不按像素亮度判定；桥/码头/浅滩（top overlay）不受影响。
- 读档救援（world.gd，R120-WATER-1b）：旧档/旧路线若把队伍停在开放水域，
  在 HUD 重建目标场时把队伍救到**与目标门同一连通分量**的最近岸格（不会救到河中小岛），然后重建距离场。
- 验证（headless，槽1 只读）：
  - 旧水面 (224,1448) `_is_obstacle=true`；桥面 (640,1608) `_is_obstacle=false`；陆地 (896,848) 可走；
  - 载入槽1：队伍从 (224,1448) 被救到 **(496,712)**（主陆地、目标连通分量）；
  - 主路径通：从 (496,712) 按 HUD 走 **64 步** 到 evt802 环内 (784,536)，出现「按空格前往」提示。

## A2) R120-WATER-1c：严格封水导致桥头/沿岸窄道断开 → 浅滩边缘保留可走
- 用户最新档（10/31 01:18，sha `F2D4EC8…`）scene50 落点 **(1600,720)**：严格封水后该区与 evt802
  所在陆地被水隔断，HUD 走到 evt802 不可达 → 旧逻辑进入“可达门 fallback”，HUD 显示「出村前往将军冢｜↑剩2格」
  但实际指向 evt803（scene53 回程门），方向/N 全错（用户截图即此）。
- 修复：`is_open_water` 对**紧贴 top 层 overlay（桥/栈道/码头）1 步内的水面边缘**返回 false（浅滩可走），
  其它开放水域仍不可走；这样桥头/沿岸窄道恢复连通，又不放行整片水面。
- 验证（headless，用户档 1600,720）：HUD 目标 evt802，**key=←，N=594**（陆路绕水真实步数）；
  真实按键逐行 **594 步、N 每步严格 −1** → (784,536) N=0，interact=802 kind=space_door「按空格前往」。
  水面 (224,1448) 仍不可走；桥 (640,1608) 可走。

## B) 将军方向「剩 N 格」不准（HUD 距离场/目标环）
- 根因（world.gd `_a19_guide_rebuild`）：门目标(mode>=4)也套用了 96/160/240 的“迷宫大环兜底”：
  玩家离门还有 200+ 格时，距离场把大环内所有格当作距离 0 → HUD 显示“剩 0 格/已到”，且没有门提示；
  同时水面被当可走后，HUD 走的是跨水捷径，N 与实际陆路步数不一致。
- 修复（R121-HUDN-1）：
  - **mode>=4 的 SPACE/触碰门只用真实门环**（`_a19_evt_ring`），N=0 时必然在门圈内、门提示会出现；
  - 仅 mode<4 的“走到某点”类目标保留 96/160/240 大环兜底（中心可能不可站立）。
- 验证（headless，槽1 只读）：
  - (224,1448) 读档 → 救到 (496,712)，HUD 目标 evt802，**N=64**；
  - 真实按键逐行走 **64 步**（N 每步严格 −1）→ (784,536) N=0，interact=802 kind=space_door，提示「按空格前往」；N 与实际可走步数一致。
  - 旧 452 步路线中约 170 步是跨水捷径，已随水面封禁失效；请按 HUD/新路线走（从岸上到 evt802 为 64 步）。
