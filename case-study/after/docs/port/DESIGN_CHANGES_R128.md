# R128 出村石桥恢复“走过触发”（替代桥头 SPACE 提示）

## 用户反馈（最新槽1）
- 10/31 03:50 save（sha `F901B4D…`）：scene50 **绝对位置 (784,536)**（草岸、紧邻小石桥），
  中央出现「按空格前往」——用户认为桥应可走过、任务提示/步数设计不合理，且人不该被指到水面/地图外。

## 根因
- evt802 在真实事件表里是 **mode5（touch normal）** 的换场景事件（脚本9712 → scene55 落点864,1696）；
  原版是**走过桥/走进触发圈自动切场景**。
- R77 起移植为“避免误切场景”，把所有 touch 场景门改成 SPACE 提示（`_space_door_ids` 拦截 + `_scan_space_door` 显示「按空格前往」）；
  在出村石桥处表现为：**桥头就弹“按空格前往”**，与“走过桥”的原版体验不符；同时 R127 收窄浅水后，桥端水面不可走，视觉上像桥没接上。

## 修复（world.gd，R128-BRIDGEDOOR-1）
1) **scene50 evt802 恢复原版 touch**：`_check_touch_triggers` 对 scene50/id802 放行（其它 touch 场景门仍保持 R77 屏蔽），
   玩家踩上桥面/走进触发圈即切 scene55；读档安全区/到达保护仍保留。
2) **移除桥头“按空格前往”提示**：`_scan_space_door` 跳过 scene50 evt802，不再误判为 SPACE 门。
3) **HUD 任务提示重设计**：
   - 目标标签：「第 3 章：出村前往将军冢（过小桥触发）」；
   - 到桥头（N=0）：「目标 第 3 章：出村前往将军冢｜已到桥头，向前走一步（踩上桥面）触发」；
   - 未到桥头：方向 + 真实最短路剩余格数（BFS 同源，N 每步 −1）。
4) 桥面（top overlay）可走；开放水面不可走；桥端/岸边连接格保留可走（R127 只封开放水面）。
