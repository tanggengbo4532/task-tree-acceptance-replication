# R174 用户批准：只走黄色土路 + 山洞连通（不改底图/不开放草丛）

## 用户批准设计
- 草丛/void/非黄色地图格不可走；只允许黄色土路/洞内石土；
- 用真实山洞门事件连通：起点黄色块 → 门 A → scene72 洞内 → 门 B → 出洞黄色块 → 目标 evt1368 → scene70；
- 不改 map 底图 tile、不改 blocked、不开放草丛。

## 实现（world.gd）
1) **只 scene69/map61、scene72/map64** 启用“黄色土路/洞内石土”白名单 walkable：
   - 按 tile 位图主色分类：土黄/棕土（r 明显大于 g、b 低）；排除草丛（r≈g/偏绿）、水、void；
   - `_is_obstacle` 在 map61/64 对非白名单格返回 true（正常移动、BFS、HUD N 同源）。
2) **读档/进场草丛救援**：若当前格不在白名单，吸附最近黄色/石土格，日志
   `[a30] grass rescue (1456,1184)->(1376,1168) scene=69`；仅救援非法落点，不放开正常移动。
3) **门 A**（scene69 起点黄色块 → scene72 洞内东侧）：
   - 动态事件 id（存 vars `cave_door_a_evt`），坐标取起点块最近黄色格 **(1376,1168)**；
   - 走近显示「按空格进入山洞（穿过山洞 → 扬州方向）」，SPACE 后进 scene72 (1696,1104) 附近。
4) **门 B**（scene72 洞内 → scene69 目标块）：
   - 动态事件 id（vars `cave_door_b_evt`），坐标取 evt1390 附近最近石土格 **(1744,1136)**；
   - HUD 指门 B，SPACE 后出洞到 scene69 目标块，并写 `a30_cave2_passed=1`；
   - 出洞落点旁给目标交互「按空格前往扬州方向（目标点）」→ 等价 evt1368 后续进 scene70。
5) HUD 只按黄/土白名单+洞门 BFS；N 每步−1。
