# R153 战斗分支回归修复：R148 把 0x0007 参数映射反了（随机战胜利被读档回滚）

## 现场（tester4，HEAD 4bdc43d）
- 用户槽1 scene55 (592,816) N=199；村道触发老虎战（HP900），两场均胜；
- 胜利后 HUD N 回 199、HP/EXP/仙术还原，画面 sha 与读档帧相同 → 精确回退到读档状态。

## 根因（R148 映射错误）
- 0x0007 参数实为 `(team, op1=失败分支, op2=逃跑分支)`，胜利无跳转、顺序执行故事脚本。
- 证据：随机战脚本（scene55 evt928-931）为 `0x7 team,41075,41073`：
  - **41075**：`0x43 1,1 / 0x4F / 0x3B / 台词13135-13138`（“胜败乃兵家常事也 大侠请重新来过吧”）`/ 0x4E 读档` → **失败/GameOver 处理器**；
  - **41073**：`0x4B` 清场 → 战利清场。
- R148 把 op1 当胜利分支：随机战胜利时 `jump(41075)` → 执行 GameOver 读档 → N/HP/EXP 精确回滚。
- A33 `0x7 29 41075 0` 也说明：op1=失败分支（GameOver），op2=0 表示无逃跑分支；胜利顺延剧情。

## 修复（script_vm.gd R153-BATTLEBRANCH-2）
- `BATTLE_LOST` → `jump(a1)`（a1=0 则顺序执行）；
- `BATTLE_FLEED` → `jump(a2)`（a2=0 则顺序执行）；
- `BATTLE_WON`/其它 → `ip+1` 顺序执行（不再 jump）。
- 保留 R148 的 0 分支保护（不会 jump(0)）。
