# R289 到达 HUD N=0 但事件不触发修复（锁妖塔 155）

## 用户最新档（5FCF6EE8…）
- scene155，pos **(1120,1176)**，可走
- HUD：「锁妖塔：走到上塔顶点（自动触发塔顶剧情）｜已到触发区」；target_evt2496，target=(1152,1120)，**N=0**
- 但 N0 位置到目标点 metric=**144**；vars a39=1、a40=0
- 原因：
  - event2496 **mode=2**；HUD 对 mode<4 的兜底目标环会尝试 96/160/240，所以 144 处就显示 N=0
  - R286 自动触发半径原为 **96**，144 不在圈内 → “到了但没反应”
- 即：HUD 的 N0 触发圈（mode<4 兜底大环）与自动触发半径不同源。

## 修复
- 锁妖塔 A39/A40 自动触发半径改为 **240**，与 HUD mode<4 兜底环（最大240）对齐；
  - A39 scene153、A40 scene155
- A41（event2521 mode=5，正常环48）保持 **96**，避免提前触发
- HUD 仍显示“已到触发区：停在圈内自动触发（不用按键，不是跳过）”
- 仍无 SPACE 跳剧情/传送；Boss/剧情战真实
