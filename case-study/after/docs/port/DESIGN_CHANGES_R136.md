## 2) 逃跑后立即重触发（真 bug，已修 R136-FLEEGUARD-1）
- 根因：战斗结束 `on_battle_finished("flee")` 后，玩家仍站在同一 mode>=4 战斗事件触发圈内；
  下一帧 `_check_touch_triggers` 再次命中同一事件 → 立即重新进入同一战斗（逃跑死循环）。
- 修复（world.gd）：
  - 新增 `_flee_guard_evt/_flee_guard_until/_flee_guard_ring`；
  - 逃跑结果时记录 `vm.last_event_object_id`，保护期 **180 帧（≈3 秒）**；
  - `_check_touch_triggers` 对该事件：保护期内或仍在原触发圈 +8 内 → 跳过；
    必须**时间到且离开原圈**才恢复可触发（不会原地 SPACE/走一步立即再打）。
  - 胜利不改变原逻辑；读档/换场景后保护会自然失效（事件 id 不同/场景重建）。
- 验证：boot exit0；无 SCRIPT ERROR；R136 逻辑为局部 trigger 门禁，不影响其它事件/路线。
