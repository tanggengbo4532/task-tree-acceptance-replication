## 根因
- R124-GROUND-1 为修 map46 tile0=草地误封，把“bottom 位图非透明 **或 top 有内容**”都算地面；
- top overlay 是桥/屋顶/装饰层，某些 void/黑底格 bottom 透明但 top 有装饰时被当成可走 → 走出原版地图边界。
- 核对：map125（scene58）tile0 位图是**全透明**（非草地），R124 本身已封掉；真正漏洞是 **top-only** 格。

## 修复（pal_map.gd R150-VOID-1）
- `has_content = 1` 仅当 **底层 tile 位图有非透明像素**；top overlay 不再单独把 void/黑底格变成可走。
- 合法桥面/栈道都有底层水面/地面 opaque，因此保留；map46 tile0 草地仍 opaque 可走（R124 保留）。
- blocked 位（真实墙/障碍）不变。
