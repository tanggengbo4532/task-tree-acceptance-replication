# R99 设计改动（用户需求 5 项）——实现规则与验收点

> 仅代码改动；不改存档二进制格式；新增的“经验规则标记”写在既有 `pal_save_<slot>.json` 的 `vars` 里。

## 1) 仙术/合击菜单显示效果与威力（辅助/治疗显示具体效果）
- 位置：战斗主菜单 →「仙术」（列表每行）与「合击」（选中后信息条）。
- 数据来源（优先级）：`Data.mkf #4 MAGIC`（`base_damage`、`cost_mp`、`type`、`elemental`）
  + `Sss.mkf OBJECT.flags`（`USABLE_TO_ENEMY`/`APPLY_TO_PLAYER`/`APPLY_TO_ALL`）
  + OBJECT 的 `script_on_use`/`script_on_success` **脚本 ops**（0x001B/1C/1D/22/2B/2C/2D/2F/3A/88 等）；无法识别显示「效果见脚本(id)」，不编造。
- 伤害技能样例：`天剑 44MP 威303 伤害 全体`、`天师符法 18MP 威140 伤害 敌方单体`；
  脚本伤害：`乾坤一掷 1MP 消耗当前全部金钱，伤害=金钱×2/5 伤害 全体`。
- 辅助/治疗具体效果（来自真实脚本，全部已核对）：
  - `气疗术 6MP 回复HP+75 己方单体`、`凝神归元 18MP 回复HP+220 己方单体`、`元灵归心术 40MP 回复HP+500 己方单体`；
  - `真元护体 18MP 附加「护」9回合 己方单体`、`天罡战气 13MP 附加「勇」7回合 己方单体`；
  - `金蝉脱壳 33MP 非Boss战逃跑(Boss战无效) 全体`；
  - 其它辅助：0x002B/2C 解毒、0x0022 复活(HP=MaxHP×n/10)、0x002D 附加状态（乱/麻/眠/封/傀/勇/护/速/连）。
- 元素/毒属性仅对伤害技能显示（治疗/辅助的 elemental 字段不代表攻击属性）。
- 目标范围：`全体`（APPLY_TO_ALL）、`敌方单体`、`己方单体`。

## 2) 战斗经验 ×2（用户调整：由 ×10 下调）
- `battle.gd _battle_won()` 开头 `exp_gained *= int(PALState.EXP_SCALE)`；当前 `EXP_SCALE=2`。
- 胜利结算文字、主经验、隐藏经验全部按 ×2 后的数值（同源）。
- 验收：胜利信息“获得经验 N”与升级后经验变化均为基础值的 2 倍。

## 3) 已有经验重算等级（含 ×10→×2 迁移）
- 触发：读档时（`PALState.load_game`）；**不改 .sav 格式**（标记写在既有 `pal_save_<slot>.json` 的 `vars`）。
- 规则：总经验 = Σ_{i=1..当前等级-1} Data#14[i] + 当前级内经验；
  新等级 = 满足 Σ_{i=1..L-1} Data#14[i] ≤ 新总经验 的最大 L（≤99）；新级内经验 = 新总经验 − 累计阈值。
- **迁移规则**：
  - 带 `exp_scale_v2`（旧 ×10 已重算并保存）且无 `exp_scale_v3`：当前总经验 ×0.2（10→2 基准等价折算）后重算等级/级内经验，
    并按固定成长回退多出的等级属性（避免保留过高属性）；然后置 `exp_scale_v3`。
  - 无任何标记的旧档：旧总经验 ×2（EXP_SCALE）重算一次，置 `exp_scale_v3`。
  - 已带 `exp_scale_v3`：不再折算（保存后重复读档不放大/不缩水）。
  - 新游戏：直接置好标记，经验全部按 ×2 规则增长。
- 验收：旧档读入后等级/属性按 ×2 语义重算；带 v2 标记的存档读到后会从 ×10 结果回退到 ×2 结果；
  连续两次读同一文件结果一致；保存后再读不重复折算。

## 4) 升级全方位属性成长
- 规则（固定、可复现；不再随机）：每级 **HP+12、MP+10、武术+4、灵力+4、防御+2、身法+2、吉运+2**，全部上限 999。
- 吉运 = `flee_rate`（原版 PlayerRoles 无独立幸运字段，沿用逃跑/吉运属性）。
- 应用点：战斗升级（`PALState.player_level_up`）与读档重算（`_apply_level_growth` 同一规则）；
  升级时按 `Data#6 level_up_magic` 学习对应等级仙术。
- 验收：每升 1 级上述 7 项全部提升固定数值（升级信息/状态菜单可见）。

## 5) Ctrl 复用上一回合技能
- 战斗主菜单（攻击/仙术/合击/其他 四向菜单）按 **Ctrl**：直接复用该角色上一回合用过的「仙术」或「合击」。
- 目标：敌人目标自动重选（单敌直接选、多敌进入目标选择、可 ESC 取消）；自身/队友目标按正常目标选择流程。
- 不可用时（无缓存/MP 不足/仙术不可用/合击条件不满足）信息条提示，并留在主菜单，不会崩溃。
- 缓存：每名玩家指令确认时记录（仅仙术/合击）；子菜单内 Ctrl 忽略，避免与取消/确认冲突。

## 6) 洞内链 HUD 走法增强（用户反馈“知道目标但不知道怎么走”）
- A19 洞内链/战斗引导的「方向键 + 剩余格数」取自 `_a19g_dist` 真实可走距离场（同源），不会指黑区；
  按中央提示逐步走即可到达触发圈（长距离如 scene48 洞厅入口→蛇妖女 118 格）。
- scene48 洞厅：若 boss 未打且装饰事件 evt762 尚未让路，HUD 文案先提示「先走近洞厅装饰触发让路」（走近会自动对白并让它自移），
  让路后再指向蛇妖女 boss；boss 打完则目标改为「石门（石钥匙→救灵儿）」并指向 evt759。
- 玩家阅读：中央条给“下一步按键 + 本图剩余格”。
- 验收：第 2 回合起主菜单按 Ctrl 应直接执行上一回合技能（目标按上述规则）。

## 7) HUD 方向防横跳（R102-STUCK-1，tester2 实机发现 scene48 (1344,616)↔(1344,624) 83↔84 死循环）
- 规则：A19/A14 洞内链 HUD 方向**只从“按一次后剩余格数严格减小”的真实可走落点中选**；
  不再用“朝目标的直线方向”兜底（该兜底可能给出会回退/横跳的方向）。
- 防回退：记录上一格位置，回到上一格若不会减小 N 则不选。
- 若当前位置四方向都不能减小：先对当前位置重建一次距离场再试；仍无则清空方向，中央显示「等待/绕行中」，绝不给出会回退的箭头。
- 方向/剩余格数同源（同一距离场）；玩家按箭头走时 N 必然每步 −1。
- 验证（headless）：从用户 scene48 (1056,752) 起按 HUD 实际按键行走 38 步，N 118→80 单调递减、无横跳，
  到达蛇妖女触发圈（(1344,592) N=80）；(1344,616)/(1344,624) 分别给出 ↑（下一步 N 严格变小）。
