# R287 ESC 菜单商店（调研 + 方案，未改代码）

## 1) 原版数据/现有实现调研
- 商店数据：`PALTables.stores`（Data#0，STORE 9w/店，共 **21 个店**），`store_items(store_id)` 返回9个 item id；`PALTables.item_of(id)`：bitmap/price/script_on_use/script_on_equip/flags
- 金钱：`PALState.cash`（int，存档 .json 保存）；背包 `PALState.inventory[] = {item, amount, in_use}`；装备 `PALState.roles["equipment"]` 6 部位×6 角色（36项）
- 物品 flags：`0x01`可用 / `0x02`可装备 / `0x04`投掷 / `0x08`消耗 / `0x10`全体 / `0x20`可卖
- 已有 `proj/game/shop.gd`：完整买/卖 UI（`setup(store_id,is_buy)`）：
  - 买：9格原版货、价格、现金、持有数、效果行；确认扣钱+`add_item`
  - 卖：背包中 `FLAG_SELLABLE` 物品（含装备）原版 **半价**；确认移除+加钱
  - `Tab` 切换买/卖；Esc 关闭；已支持效果预览
- ESC 主菜单 `menu.gd MainController` 当前4项（状态/仙术/物品/系统，word id3/4/5/6），`_main_index` clamp0..3

## 2) 建议实现（用户确认后写）
### 入口
- ESC 主菜单第4项改为 **商店**（状态/仙术/物品/**商店**/系统），新增 `LABEL_SHOP`（文本「商店」，word缺失则直接字符串）
- 主菜单5项导航（clamp0..4，方向循环5）；选中商店打开 `shop.gd`
- 商店关闭后返回世界（或返回菜单二选一，默认返回世界）

### 商品池（默认：随进度原版装备店）
- 不新增数据，按进度选原版装备店：
  - 早期（未到第4章）：store **3**（木剑/藤甲/草鞋/皮帽…）
  - 第4章（a31）：store **2**（短刀/护肩/披风/铁履…）
  - 第5章（a36）：store **6**（长剑/大刀/越女剑/铁锁衣…）
  - 锁妖塔后/第6章（a38/a41）：store **10**（九截鞭/玄铁剑/青锋剑/青铜甲/铁鳞甲…）
  - 终章（a44/a48）：store **16/17**（苗刀/鬼牙刀/天蚕宝衣/冲天冠…）
- 保留原版价格；卖价原版半价（已有 shop.gd）
- 备选：**全部装备可买**（便利版）——需给 shop.gd 加分页/上下页（208件装备，现有13格列表不够）；默认不选，等用户确认

### 买卖/装备流程
1. Esc→商店→购买页：Tab/左右切出售；商品价格、现金、持有数、效果行
2. Enter→确认框→买：扣 cash+add_item 1；钱不足 toast；背包满按现有 add_item 结果提示
3. 卖：列表=背包可卖物品（含装备），价格=原价/2，确认后 remove+cash+
4. 购买后不自动装备；玩家打开「物品」→选装备→原版 EquipItemController 装备（不改装备逻辑）
5. 关闭/存档：只改运行期 cash/inventory/equipment；不新增存档字段，不自动覆盖槽1

### 代码落点（预计）
- `menu.gd`：MainController labels/索引/5项布局；`open_shop_for_menu()` 实例化 shop.gd，`closed` 关闭菜单；按进度返回 store_id
- `shop.gd`：若走“随进度原版店”无需改逻辑，只增加可选标题；若走“全部装备”再加分页/自定义池
- `world.gd`：无需战斗/任务数值改动；商店只在菜单运行期操作
- 不改 Data.mkf / 存档格式 / 战斗与任务数值
