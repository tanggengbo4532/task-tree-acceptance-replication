## Lead 根因修复记录

| 问题 | 根因 | 修复 |
|---|---|---|
| 场景4黑屏 | `load_scene` 对无 onEnter 场景执行默认落点，覆盖门脚本 0x0046 设置 | `_position_scripted` 标记；只有未设置时回地图中心 |
| 对话结束脚本卡死/[脚本]残留/角色不能动 | `DialogBox.advance()` 关闭时也返回 true，world 的 `not advance()→vm.advance_dialog()` 永不触发 | 关闭时返回 false |
| 读档重播/不回原位 | `loaded_from_save=true` 写在 `load_game` 不可达代码 | 移到读档开头 |
| 移动卡死/极慢 | 2px 中间像素触发半格判定，破坏 sdlpal 16/8 离散位置语义 | 离散格点步进（16/8px + 冷却），碰撞只查落点；脱困吸附格点 |
| 中窗对话只显示半句 | 对 kDialogCenterWindow 用了打字机，1.4s 自动关 | 中窗整句瞬显 + 1.4s 自动关（text.c 语义） |
| 战败无处理 | 未实现 Game Over | 全队 HP0/战败 → 中窗提示「胜败乃兵家常事，大侠请重新来过……」2.5s → 回标题 |
| 逃跑失败无提示 | 提示仅 20 帧(0.33s)太短 | 延长到 45 帧 |
| 战斗“其他”子菜单压状态行 / 提示不清 | 列表起点 y268 与底部状态行 y350 重叠 | 列表移到 (220,112) 起；提示标注十字键 |
| 商店买不了 | 新会话金钱 0（非 bug），但无法验收 | F12 调试给 2000 文钱；商店商品/金钱显示正常 |
