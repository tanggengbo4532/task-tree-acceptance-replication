# Case Study：PAL98 Godot 移植（初始 Bug 版）

这是本框架（`game-playtest` 插件）的**压力测试案例**，用于复现「从满是 bug 到修复通过」的完整黑盒验收过程。

> 本目录只含**初始 bug 版**源码（对应原始 commit `5c5d0f8`），保留验收开始时的全部缺陷，**不包含修复后的代码**。

## 定位

- 架构是本仓库主角（见仓库根 `README.md` / `SKILL.md`）；
- 本案例只用于**验证架构有效性**，不是游戏开发本身。

## 内容

- `game/` — 玩法层脚本（世界、战斗、菜单、对话、存档）
- `pal/` — 底层引擎（MKF、地图、精灵、状态、脚本 VM）
- `tools/` — 数据格式解析与自检脚本
- `docs/` — 移植与逆向说明（文字版，无截图）
- `main.gd` / `main.tscn` / `project.godot` — 工程入口

## 运行

1. 安装 Godot 4.7.x（Mono 版）。
2. 准备《仙剑奇侠传 98 柔情版》的**合法安装数据**（`*.mkf`、`M.msg`、`Word.dat`）。
3. 在 `pal/pal_config.gd` 中把数据目录指向你自己的安装路径。
4. 打开 `project.godot` 运行。

> 本目录**不包含**任何原始游戏数据、音乐、图片或文本。原版资源版权归其权利人所有，请使用你合法拥有的安装。
